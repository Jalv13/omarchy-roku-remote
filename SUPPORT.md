# Support

For setup trouble or a reproducible bug, open a GitHub issue and include:

- Roku Remote version
- Omarchy and Quickshell versions
- Roku model and Roku OS version
- Whether discovery, manual IP entry, or both were attempted
- The exact error shown in the panel
- Relevant shell logs from
  `journalctl --user -u omarchy-shell -n 100 --no-pager`

Remove public IP addresses, account information, and other private network data
before posting logs. For vulnerabilities, follow [SECURITY.md](SECURITY.md)
instead of opening a public issue.

The most common connection fixes are documented in the README's
**Troubleshooting** section.
